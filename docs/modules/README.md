# 创新模块

本目录记录论文创新模块的职责、数据边界、执行流程、产物和关闭行为。模块文档描述当前确定的设计，不在这里维护实验结果。

| 模块 | 状态 | 文档 |
|---|---|---|
| Analysis | 已实现，当前主实验使用 | [经营状态分析](analysis.md) |
| Deliberation | 方案阶段，尚未实现 | 实现前补充独立设计文档 |
| Reflection | 方案阶段，尚未实现 | 实现前补充独立设计文档 |

三个模块按 `Analysis → Deliberation → Reflection` 递进。关闭全部模块时，决策输入和调用链必须与 Baseline 一致。
