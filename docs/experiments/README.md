# 实验文档

本目录维护实验如何运行、如何查看产物、如何计算指标以及论文结果如何呈现。

| 文档或目录 | 作用 |
|---|---|
| [实验产物与离线评价](artifacts-and-evaluation.md) | 说明运行目录、数据来源、单次评价、多次聚合和开题绘图命令 |
| [正式实验进度汇报](progress-reporting.md) | 统一并行实验的可比节点、运行状态、经营状态和成本汇报口径 |
| [实验结果设计](results/README.md) | 汇总研究问题、指标目录、阶段方案和候选图表 |

实验执行配置属于工程入口，见 [实验配置](../engineering/configuration.md)。经营指标口径不得散落在运行指南中，应统一更新 [实验指标目录](results/metric-catalog.md)。
