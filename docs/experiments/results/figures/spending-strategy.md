# 经营支出策略

## 1. 研究问题

实验组与 Baseline 在投入时点和结构上是否存在稳定、可解释的差异，例如提前扩容、增加研发，或阶段性调整广告和客户运营投入。

## 2. 候选指标

按周汇总算力、容量、广告与获客、运营、产品研发与研究等支出。权威数据来自 `world.nmdb/ledger`，分类必须覆盖实际出现的全部账本类别。

## 3. 建议表达

若时点差异重要，使用按支出类别拆分的折线小图；若只关心全周期结构，则结果表或差额分解已经足够。每条线基于多次运行，不使用单组堆积面积图掩盖组间差异。

## 4. 保留条件

只有支出发生时间能够解释现金、增长或服务结果时才进入正文。若只是重复现金差额来源，则移至附录或不单独成图。
