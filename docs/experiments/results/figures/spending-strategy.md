# 经营支出策略

## 1. 研究问题

实验组与 Baseline 在投入时点和结构上是否存在稳定、可解释的差异，例如提前扩容、增加研发，或阶段性调整广告和客户运营投入。

## 2. 候选指标

按周汇总算力、容量、广告与获客、运营、产品研发与研究等支出。权威数据来自 `world.nmdb/ledger`，分类必须覆盖实际出现的全部账本类别。

## 3. 建议表达

根据研究问题选择两种形式：

- 若时点差异重要，使用按支出类别拆分的折线小图，观察何时增加或削减投入。
- 若需要比较当前支出策略，使用并列的水平堆叠条形图，左侧展示截至同一节点的累计成本结构，右侧展示最近 7 天成本结构。两组必须使用相同类别、顺序和坐标尺度，并同时标注总支出。

累计结构容易被一次性研究项目主导，最近 7 天结构用于补充说明当前持续经营成本。两种窗口不能互相替代。每条时序线基于多次运行，不使用单组堆积面积图掩盖组间差异。

## 4. 保留条件

只有支出发生时间能够解释现金、增长或服务结果时才进入正文。若只是重复现金差额来源，则移至附录或不单独成图。
