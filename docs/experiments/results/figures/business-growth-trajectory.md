# 客户与持续收入轨迹

## 1. 研究问题

实验组与 Baseline 的客户规模和持续收入如何演化：是否更早进入增长、更稳定地扩大业务，或在前期扩张后出现明显流失。

## 2. 候选指标

- MRR。
- 活跃个人订阅数。
- 企业订阅席位数。
- 每日新增与结束订阅数，用于解释存量曲线的转折。

这些指标的终态已经进入多维经营结果。本图只有在增长阶段、转折时间或长期稳定性提供额外信息时才单独保留。

## 3. 建议表达

MRR 作为持续收入能力的核心时序，可以单独使用日级折线图；横轴以周标识，但保留每日数据点。需要同时解释客户结构时，再使用 MRR、个人订阅和企业席位三个保留原始单位的分面折线图，并用新增与结束订阅辅助解释关键转折。

每条线表示实验组多次有效运行的均值，误差带表示运行间标准差；只有单次运行时直接显示原始轨迹，不绘制误差带。破产后不补零，并标注每周有效运行数量。

## 4. 数据来源

经营指标必须从 `world.nmdb` 中的经营事实生成，不从运行日志读取。日级存量轨迹来自 Agent 不可见的 `_eval_subscription_day`；新增和流失来自 `_eval_subscription_event`。增长率、流失率和集中度等派生指标在离线分析阶段计算。

## 5. 当前状态

- 终态与日级历史数据均已具备。
- 两张 `_eval_` 表只用于实验后复盘，不进入 Agent 的 Observation 或工具查询结果。
- 单次正式实验的阶段性预览已经验证 MRR 曲线能够显示明显的增长阶段、平台期和回落。
- 是否进入正文等待实验现象判断。
