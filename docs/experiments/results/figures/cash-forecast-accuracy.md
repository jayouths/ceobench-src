# 现金预测准确性

## 1. 研究问题

创新模块是否帮助 Agent 更准确地理解当前经营状态、现金变化规律和决策的延迟后果。

该指标解释创新模块为何可能改善长期决策，不替代最终现金、破产率和生存天数等核心结果。

## 2. 指标与数据

预测来自 `world.nmdb/predictions`，真实现金来自目标日期前 `ledger.amount` 的累计值。主指标为绝对百分比误差：

```text
APE = |预测现金 - 实际现金| / |实际现金| * 100%
```

辅助指标包括有符号百分比误差、95% 区间覆盖率和区间相对宽度。

## 3. 样本口径

- 只评价目标日期已经真实发生的成熟预测。
- 不外推第 497 天之后的现金，不用破产日现金代替未来真实值。
- 先在每个 run 内、每个期限上聚合，再使用 run 级结果比较实验组。
- 正文优先采用原论文“前四周提交的 28 天预测”口径；其他期限作为扩展分析。

## 4. 建议表达

按预测期限使用分面点图或结果表，展示每个 run、组均值、标准差和有效预测数。覆盖率与区间宽度不能与点预测误差合成一个综合分数。
