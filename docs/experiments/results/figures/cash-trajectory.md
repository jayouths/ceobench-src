# 现金轨迹

## 1. 研究问题

- 实验组是否比 Baseline 获得更高的最终现金？
- 优势是否在长期运行中持续积累，而不是末期偶然产生？
- 各组是否出现破产或明显现金回撤？

现金是 CEO-Bench 的核心评价指标，终态值和变化轨迹均必须报告。

## 2. 指标与数据

权威数据来自每次运行 `world.nmdb/ledger`。按日累计账本金额得到现金余额，论文主图保留每日一个数据点；横轴以周为单位，每 7 天显示一个周刻度。运行日志中的现金只用于交叉校验。

## 3. 建议表达

- 横轴为模拟周，纵轴为现金余额，但折线使用每日现金点。
- 每条线表示实验组多次合规运行的均值，误差带来自运行间标准差。
- 同时标记破产和主要现金回撤；每个时间点注明有效运行数量。
- 开题阶段比较 `baseline` 与 `analysis`，最终论文再增加后续消融组。
