# 经营指标方向预测

## 1. 研究问题

历史复盘经验能否提高 Agent 对未来经营指标上涨、下降或持平的预测准确性。

## 2. 合理比较

- `analysis-deliberation`：生成未来方向预测，但不使用历史复盘经验。
- `full`：生成相同口径预测，并使用 Reflection 沉淀的历史经验。

Baseline 和 Analysis 没有被要求生成同口径预测，不能构造其方向命中率。因此本方案不属于开题阶段。

## 3. 数据要求

每次预测至少记录 run ID、预测时点、目标指标、预测期限、预测方向、到期真实值和命中结果。当前尚未实现对应能力和采集链路。

## 4. 待对齐设计

- 固定预测指标与期限。
- `up`、`down`、`flat` 的判定阈值。
- 是否增加简单趋势规则作为非 LLM 参照。
- 使用最终命中率还是滚动命中率表达结果。
