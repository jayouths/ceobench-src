# 模型成本收益

## 1. 研究问题

创新模块增加了多少模型调用成本，这些额外成本对应了多少模拟经营结果提升。

## 2. 核心指标

- 决策 Agent 与各创新模块的调用次数、Token 和 API 成本。
- 整次实验 Agent API 成本。
- 实验组相对 Baseline 的最终现金增量。
- 实验组相对 Baseline 的 Agent API 成本增量。
- 每增加 1 美元 API 成本对应的模拟现金增量。

环境 LLM 成本与 Agent 成本分开报告。不同模型的 Token 不直接相加构造效率指标，跨模型比较统一使用按锁定单价计算的 API 成本。

## 3. 建议表达

优先使用结果表或“API 成本—最终现金”散点图：横轴为每次运行 Agent API 成本，纵轴为最终现金，每个点代表一次运行。只有两个实验组时不强行宣称存在效率前沿。

增量比值作为辅助统计，不能取代原始成本和原始经营结果。模拟现金与真实 API 支出必须明确区分，不能表述为真实商业利润。
