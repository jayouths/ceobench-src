# 多维经营结果

## 1. 研究问题

创新模块提高现金收益时，是否也改善持续收入、个人市场、企业市场和近期盈利能力，而不是依靠消耗已有现金或牺牲长期经营能力获得表面优势。

## 2. 默认指标

主结果固定报告：

- 最终 MRR。
- 活跃个人订阅数。
- 企业订阅席位数。
- 末四周平均每周净现金流。

其他持续经营、服务风险和客户质量指标统一在 [指标目录](../metric-catalog.md) 中维护。正式实验前可以从 P1 指标中锁定少量补充指标，但不在图表文档中重复维护候选池。

## 3. 建议表达

- 每个指标一个分面点图，保留美元、订阅数和席位数等原始单位。
- 每次重复实验显示一个观测点，大点和误差线表示组均值与标准差。
- 不归一化为极坐标图，也不合成缺乏理论权重的经营综合得分。
- 配套结果表报告原始值、均值、标准差、有效样本数及相对 Baseline 的变化比例。

## 4. 样本处理

破产运行的终态不能与其他运行第 497 天直接比较。主结果应先报告破产率和生存天数；终态经营指标只在完成相同实验时长的运行之间比较，并标注有效样本数。
