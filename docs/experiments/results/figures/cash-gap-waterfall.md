# 现金差额来源

## 1. 研究问题

实验组相对 Baseline 的最终现金差额来自更多经营收入、更低经营支出，还是增加研发和服务投入后获得的长期回报。

## 2. 计算口径

对每个账本类别计算：

```text
该类别对现金差额的贡献
= 实验组该类别累计账本金额均值
- Baseline 该类别累计账本金额均值
```

`ledger.amount` 中收入为正、支出为负。因此，更多收入和更少支出形成正贡献，更多支出形成负贡献。

建议将底层类别归并为订阅收入、广告收入、算力、容量、广告与获客、运营、产品研发、市场与客群研究。正式提取时必须检查未归类类别，不能静默丢弃。

## 3. 勾稽要求

```text
初始现金 + 除初始资金外的全部账本金额 = 最终现金
各类别贡献之和 = 实验组平均最终现金 - Baseline 平均最终现金
```

只有完成相同实验天数的运行才能直接比较累计收支。提前破产运行先进入生存分析，不与完整 497 天结果混算。

## 4. 建议表达

使用瀑布图逐项累加现金贡献。正负贡献使用不同颜色，最终总计必须与组间现金差额完全一致。开题阶段比较 Analysis 与 Baseline，最终论文可为其他消融组生成同口径附图。
