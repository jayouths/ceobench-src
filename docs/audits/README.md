# 审计台账

本目录保存影响实验正确性、组间公平性或恢复一致性的问题复核记录。

| 文档 | 作用 | 状态 |
|---|---|---|
| [模拟世界 P0 审查](simulator-p0-audit.md) | 记录模拟规则、公开信息、工具边界和恢复行为的逐项审查证据 | 持续维护，含已处理项和待复核项 |
| [上游分叉改动复核](upstream-divergence.md) | 记录分叉后上游改动与本地修复的重叠、差异及逐项处理进度 | 持续维护，仅部分事项已核对 |

审计台账保留历史上下文，因此可能描述旧实现。了解当前工程行为时，应优先阅读 [工程架构](../engineering/architecture.md) 和对应代码；确认某项问题的发现与处理过程时，再查阅本目录。
