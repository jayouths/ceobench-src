## 处理原则

- 上游经营规则和公开任务定义是判断作者意图的主要依据，但不整批移植其目录结构或实现。
- 先比较实际行为和 Agent 可见契约，再决定本地是否需要修改。仅讨论过的事项不记为“已覆盖”。
- 任何模拟规则修复都应在相同版本下重新运行 Baseline 和创新组；历史实验仍按原代码版本解释，不与新版本结果直接混比。
