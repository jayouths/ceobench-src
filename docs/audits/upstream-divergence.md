# 上游分叉改动复核台账

本台账记录本地实验分支与 CEO-Bench 上游的行为差异及处理进度，不代表已合并上游代码。当前比较基点为 `d2b7b32`，上游目标为 `bef4a28`（`upstream/main`）；继续复核前，应先确认目标提交是否变化。

**本轮范围已复核完成。** 目标范围的 4 个提交、37 个变化文件均已归类：需要的行为已吸收，本地已等价覆盖的保留现状，不采用的机制及原因在下表明确记录。完成范围仅限上述提交差异，不代表模拟器不存在其他问题，也不代表已执行新一轮真实模型实验。

## 处理原则

- 上游经营规则和公开任务定义是判断作者意图的主要依据，但不整批移植其目录结构或实现。
- 先比较实际行为和 Agent 可见契约，再决定本地是否需要修改。仅讨论过的事项不记为“已覆盖”。
- 任何模拟规则修复都应在相同版本下重新运行 Baseline 和创新组；历史实验仍按原代码版本解释，不与新版本结果直接混比。
